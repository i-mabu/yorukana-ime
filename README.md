# よるかな IME（YoruKana）

Android 用オリジナル日本語 IME。完全オフライン・ネットワーク権限なし。
名前は「終夜（よる）」の世界観から。夜テーマ（濃紺）を既定にした、育つ IME です。

| 項目 | 内容 |
|---|---|

| 状態 | 再構築版（旧 v1.4.5 から作り直し、機能パリティ済み） |

## 機能

### 入力方式（4種、モード切替キーで循環）

| 方式 | 内容 |
|---|---|
| ローマ字入力（QWERTY） | ローマ字→ひらがな変換しながら composing 表示。促音（子音重ね・xtu/ltu・xtsu/ltsu・tch）、撥音 n（nn / n' 対応、後続が母音・y なら な行/拗音）、拗音（kya/sha/cha/ja 等）、外来音（fa/fi/fe/fo、ti→てぃ、di→でぃ、wi/we、va 行 等）、小書き（xa/xya/xtu 等）を含む変換テーブル。最上段キーの長押し（450ms）で数字 1〜0 |
| かな入力（12キー） | あ/か/さ/た/な/は/ま/や/ら/わ の10キー。フリック入力（既定）とトグル打ちを設定で切替。文脈キー「゛゜小」で濁点・半濁点・小書きを循環（か→が、は→ば→ぱ、つ→づ→っ、あ→ぁ、う→ゔ→ぅ 等）。文脈キー「カナ」で未確定文字列をカタカナ化 |
| 英数入力 | フリック配列（既定、Simeji の英字12キー準拠: ABC/DEF… の11グループ、タップ循環対応）と QWERTY 直接入力（数字行・シフト対応）を設定で切替。composing を経ず直接コミット |
| 記号・絵文字 | カテゴリタブ式（常用/カッコ/図形/数字/顔文字/絵文字）。顔文字18件・絵文字60件はタップで直接コミット |

#### かなキーボード配置（Simeji 準拠、5列×4行）

全行とも列の weight は [0.75 / 1 / 1 / 1 / 0.75]、キー高さは 58dp で統一。

| 行 | 左列（0.75） | 中央3列（かなキー） | 右列（0.75） |
|---|---|---|---|
| 1 | 記号 | あ か さ | ⌫ |
| 2 | ← | た な は | → |
| 3 | 123 / カナ（文脈） | ま や ら | ⏎ |
| 4 | あA | ゛゜小 / 顔文字（文脈）、わ、、。？！ | 変換 |

- 行3左と行4の2番目は文脈キー: 未確定文字列が無ければ「123」「顔文字」（各パネルへ遷移）、あれば「カナ」「゛゜小」になる
- 「、。？！」キーはタップごとに 、→。→？→！ を循環して入力する
- 「あA」は英数モードへの直接切替

#### フリック配列

タップ = 中央、左/上/右/下フリック = その方向の文字。押したキーの真上に横並びストリップのプレビュー（左・中央・上・右・下の順）が出て、現在の方向のセルが強調され、指を離した位置で確定する。しきい値（20dp）未満で離した場合はタップ扱いで、トグル循環（あ→い→う→え→お）も併用できる。

| キー | 中央 | 左 | 上 | 右 | 下 |
|---|---|---|---|---|---|
| あ | あ | い | う | え | お |
| か | か | き | く | け | こ |
| さ | さ | し | す | せ | そ |
| た | た | ち | つ | て | と |
| な | な | に | ぬ | ね | の |
| は | は | ひ | ふ | へ | ほ |
| ま | ま | み | む | め | も |
| や | や | （なし→や） | ゆ | （なし→や） | よ |
| ら | ら | り | る | れ | ろ |
| わ | わ | を | ん | ー | 〜 |

### 変換エンジン

| 項目 | 内容 |
|---|---|
| 候補順 | ⓪ユーザー辞書（最優先）→ ①辞書の漢字候補（学習頻度でソート）→ ②カタカナ → ③ひらがな原文 → ④ローマ字原文（重複排除、候補バーは最大24件） |
| 内蔵辞書 | 読み 3,410 件。明示エントリに加え、五段（行くの例外含む）・一段・い形容詞・な形容詞の活用形を生成。1文字読みには単漢字フォールバック |
| 助詞分離 | 末尾助詞（はがをにへとのかもねよ）を分離し、語幹候補 + 助詞 を提示 |
| 文節分割 | 全体が辞書に無い長い入力でも、助詞の位置（最大深度3、サ変動詞の語頭も区切り）で文節に区切って変換・予測する |
| 予測候補 | 前方一致する辞書語を候補バーの後ろに表示（ユーザー辞書→内蔵辞書、頻度→読みの短さ順）。末尾セグメントへの予測も併用 |
| 学習 | 確定した候補の頻度を端末内に保存し、候補順に反映（ひらがな原文・ローマ字原文そのままの確定は学習しない） |
| ユーザー辞書 | 設定画面で よみ（ひらがな）→ 単語 を登録。変換候補の最優先に出る。予測候補にも出る |

### その他

| 項目 | 内容 |
|---|---|
| セキュアセッション | パスワード欄（text/number の password variation）と学習抑制指定（IME_FLAG_NO_PERSONALIZED_LEARNING）の入力先では英数モードに固定し、学習記録を行わない |
| セーフティ | 起動直後のクラッシュが連続すると段階的に機能を落として起動する（2回以上: セーフモード = 学習の永続化・ユーザー辞書・バイブ停止 / 4回以上: 最小モード = 変換エンジンとプレビューも停止）。クラッシュ記録は設定画面で確認・消去でき、セーフモードは手動解除も可能 |
| テーマ | 夜テーマ（濃紺、既定）/ 昼テーマ（明色）。設定画面の配色にも連動 |
| プライバシー | ネットワーク権限なし（宣言する権限は VIBRATE のみ）。入力内容・学習データは端末外に一切出ない。allowBackup=false |
| フルスクリーン | 横向き等のフルスクリーン抽出モードは常に無効化し、通常の高さで表示 |

## 設定（設定画面の項目）

| 設定 | キー（yorukana_prefs） | 値 / 既定値 |
|---|---|---|
| テーマ | `theme` | `night`（既定）/ `day` |
| キータップ時にバイブレーション | `vibrate` | `true`（既定）/ `false` |
| 既定の入力方式 | `default_mode` | `romaji`（既定）/ `kana` / `en`。ただし subtype の指定（mode=romaji / mode=kana）が優先 |
| かな入力方式 | `kana_style` | `flick`（既定）/ `toggle` |
| 英数入力の配列 | `en_layout` | `flick`（既定）/ `qwerty` |
| ユーザー辞書 | `user_dict` | `よみ\t単語` を改行で連結した文字列 |
| 学習頻度 | `freq:<読み>\|<候補>` | Int（選択回数）。設定画面から全リセット可能 |

セーフティの状態は別ファイル `yorukana_safety` に保持する（本体の設定ファイルが壊れても判定を続けるため）。

## ビルド方法

Gradle/AGP を使わない手動ビルドです。JDK 21 と Android SDK（platforms;android-34 / build-tools;34.0.0）、Kotlin 2.0.21 が必要です。

```sh
./build.sh            # 単体テスト + デバッグ APK (dist/yorukana.apk)
./build.sh --skip-tests
./tests/run-tests.sh  # 単体テストのみ (純ロジック 324 件)
```

- 依存ライブラリ（Compose 等）は `tools/resolve.py` が Maven から `libs/` へ自動取得します（初回のみネット必須）。Compose コンパイラプラグインと R8 は `build-apk.sh` が取得し、SHA-256 を検証します
- リリースビルドは `./build.sh release`（環境変数 `RELEASE_KEYSTORE` / `RELEASE_KEYSTORE_PASS` / `RELEASE_KEY_ALIAS` / 任意で `RELEASE_KEY_PASS` が必要。出力は `dist/yorukana-release.apk`）
- ビルドの最後に `aapt2 dump badging` で package / version / SDK / 権限（VIBRATE のみ、INTERNET なし）を自動検証します

## テスト

`tests/run-tests.sh` で純ロジック（ローマ字変換・かなユーティリティ・辞書/変換エンジン・フリック解決・英数フリック・ユーザー辞書・セーフティ判定・記号データ）の単体テストを実行します（324 件）。
